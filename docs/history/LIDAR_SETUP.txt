Coordinate rules to preserve for later flight integration
-------------------------------------------------------
Isaac world is treated as ENU by the current bridge: X=east,Y=north,Z=up.
Isaac body is FLU: X=forward,Y=left,Z=up. PX4 is NED/FRD.
  vector ENU -> NED: (x,y,z) -> (y,x,-z)
  vector FLU -> FRD: (x,y,z) -> (x,-y,-z)
These vector conversions do not align different local origins. A world-space
waypoint also needs the measured PX4/Isaac origin offset and frame alignment.
Body directions need the current vehicle orientation to become local NED.
Use the LiDAR frame transform first; header.frame_id alone is not conversion.
PX4 timestamp synchronization is a separate concern from ROS /clock. Avoid
changing ros2_hover.py timestamps until the installed PX4 synchronization path
is checked. The LiDAR probe never sends PX4 timestamps or setpoints.
